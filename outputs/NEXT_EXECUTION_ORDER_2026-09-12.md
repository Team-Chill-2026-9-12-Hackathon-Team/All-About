5. 主故事固定为“识别适用来源 → 发现截止日期更新 → 解释更新依据 → 展示原文与未知项”。

## UI 改造后的页面顺序

1. 直接进入 Course Desk，不经过假登录和工具选择。
2. 初始页只展示一句价值主张、问题输入和 3 个经过验证的 starter。
3. 运行时左侧显示问题与精简进度，右侧显示真实 Viewer；模式标签始终可见。
4. 完成后左侧首先显示 Answer Hero，右侧自动切为 Evidence Workspace。
5. 引用点击联动原文；Coverage Receipt 和完整过程放在可展开区域。
6. History、Keychain、设置只作为次级入口；比赛未完成的功能不出现。
